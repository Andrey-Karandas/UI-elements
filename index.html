Radio Buttons — є типом інструменту вибору, який дозволяє користувачам вибрати лише один варіант зі списку вибору.

Checkbox — дають користувачам змогу вибрати одну або кілька опцій зі списку. Часто використовуються у формах або налаштуваннях, щоб дозволити користувачам вибрати свої переваги.
Text input — це елемент інтерфейсу, що дозволяє користувачу вводити текст, цифри або символи з клавіатури в одному рядку на вебсторінці або в програмному додатку
Tabs — вкладки надають користувачам можливість переміщатися між різними розділами або переглядами в програмі чи на сайті.

Button — інтерактивні елементи, які користувачі можуть натиснути, щоб ініціювати дію або надіслати форму. Вони часто мають мітки, що вказують на дію
Text label — це текстова мітка або підпис, що використовується для пояснення або ідентифікації елемента, наприклад, у графічних інтерфейсах або на веб-сторінках
link
Link – це гіперпосилання в Інтернеті або тексті, яке дозволяє перейти на іншу веб-сторінку, файл або розділ документа
info_outline
Tooltips — підказки надають додаткову інформацію або контекст, коли користувачі наводять курсор на певні елементи, або клацають їх. Можна використовувати для пояснення призначення, або як функціональні кнопки, піктограми, чи посилання.
